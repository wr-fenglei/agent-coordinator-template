# 会话协调者模板

用于协调多个 Codex 会话的 AGENTS.md 模板, 记录协调职责, 会话索引和各角色当前维护的项目

## 文件

- `AGENTS.md`: 通用模板, 使用占位符, 不包含真实会话标识或本机路径

## 使用

1. 将 `AGENTS.md` 复制到协调会话的工作目录
2. 填写协调者与角色的名字, 职责, 会话标识和目录
3. 按实际情况填写项目简介, Git 仓库和维护方式, 无仓库时删除对应项
4. 有其他配置, 应用或环境的改动时, 在额外影响中说明修改位置及影响对象
5. 核对当前会话是否加载规则, 文件可被读取不代表已自动加载

协调会话一节只记录协调职能, 协调者兼任项目维护时, 在会话索引和角色会话列表中记录其项目职责

会话目录与仓库目录可以不同, 一个会话更换维护项目时更新对应角色的内容, 保留会话身份

## 维护

通用结构和协调规则变化时更新模板与本说明, 真实分工在使用者本地维护, 不提交到公开仓库

本模板记录分工与操作要求, 不提供自动调度程序, 实际转交和跟进依赖使用环境提供的会话工具
